# Redirect for jwj1342.github.io

This branch is what GitHub Pages publishes at https://jwj1342.github.io. It holds no
site, only two pages that send every visitor to the same address on https://wenjia.me
(`index.html` for the homepage, `404.html` for every other address).

The site itself is on the `master` branch and is served by Cloudflare.
